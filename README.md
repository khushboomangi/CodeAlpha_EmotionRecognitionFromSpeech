# Speech Emotion Recognition — CodeAlpha Machine Learning Task 2

## 📌 Overview
This project classifies human emotions (Happy, Sad, Angry, Neutral) from speech audio features using Audio Signal Processing and Deep Neural Networks.

## 🛠️ Features & Methodology
- **Feature Extraction:** Librosa (MFCC - Mel-Frequency Cepstral Coefficients)
- **Model Architecture:** Multi-Layer Perceptron (Neural Network)
- **Performance Metrics:** Accuracy, Precision, Recall, F1-Score, Confusion Matrix
